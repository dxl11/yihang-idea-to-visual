# Title Generation — STEP 02

## Source of truth

Use **only** `content/final-article.md` (locked). Do not invent angles absent from the article.

## Default deliverable

Provide **5 titles** with clearly different communicative intents. Example directions (adapt to content; do not always use the same five labels):

| Direction | Intent |
|---|---|
| Viewpoint | Assert a clear stance |
| Reflective | Invite contemplation |
| Question | Open with a sharp question |
| Spread / viral | Emphasize a hook for sharing (without distorting meaning) |
| Suspense | Create curiosity without clickbait lies |

## Quality bar

- Distinct: not five paraphrases of one sentence
- Faithful: each title must be defensible from the article
- Platform-aware length later; at this stage prioritize meaning over character hacks
- Prefer the author's vocabulary when distinctive

## Interaction

1. Present titles with a one-line rationale each.
2. Allow choose / edit / regenerate.
3. On confirmation, write `content/title.md` and set `title_locked`.
4. Ask whether to enter cover design.

## After article re-lock

If article version changes, mark titles as stale and regenerate or reconfirm before cover work.

# 09-naturalist-specimen — Naturalist Specimen

- **风格名称（EN）：** Naturalist Specimen
- **中文说明：** 自然博物志标本海报
- **Prompt ID：** `09-naturalist-specimen`
- **上下区域比例：** 上 45% / 下 55%
- **适用场景：** 博物馆档案、艺术出版物
- **推荐照片类型：** plant, animal, object, architecture
- **核心视觉特征：** 标本线描、奶油旧纸、克制色块

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将单张照片制作成3:4竖版的自然博物志艺术海报。
上半部分保留原始照片。
下半部分将主体转化为自然历史博物学标本风格。
如果原图是植物、动物或自然物体，提取其准确的形态特征，以细密线描、平面剪影和克制的色彩还原。
如果原图是建筑、器物或其他非自然主体，则改用对应的收藏品档案式表现，不得强行添加植物或动物元素。
采用奶油色旧纸、细线描和少量褪色色块。
主体居中或稍偏右，布局克制。
允许预留标本编号、收藏日期和简短英文说明区域，但不能虚构科学分类和真实编号。
整体具有历史博物馆收藏档案和艺术出版物质感。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 虚构科学分类
- 强行加动植物
- 乱码编号
- 多图

## 最终检查要点

- 按主体类型选表现
- 45/55
- 非虚构标注
- 单张

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

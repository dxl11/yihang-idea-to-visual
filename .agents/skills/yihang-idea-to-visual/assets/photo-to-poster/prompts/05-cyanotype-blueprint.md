# 05-cyanotype-blueprint — Cyanotype Blueprint

- **风格名称（EN）：** Cyanotype Blueprint
- **中文说明：** 蓝晒艺术蓝图
- **Prompt ID：** `05-cyanotype-blueprint`
- **上下区域比例：** 上 50% / 下 50%
- **适用场景：** 自然科学实验、现代艺术蓝图
- **推荐照片类型：** architecture, plant, object, portrait
- **核心视觉特征：** 靛蓝/普鲁士蓝、结构线、奶白负空间

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将用户提供的单张照片制作成3:4竖版艺术海报。
上半部分保留原始照片，保持原始主体和真实场景。
下半部分将主体转化为蓝晒摄影和技术蓝图风格的艺术表达。
以深靛蓝和普鲁士蓝作为主体色，以奶白色作为线条和负空间。
主体通过清晰的剪影、细密轮廓线和结构线表达。
对于建筑和物体，可以提取结构关系。
对于植物和自然场景，可以提取枝叶和自然形态。
对于人物，可以保留姿态和轮廓。
整体像一件自然科学与现代艺术结合的实验作品。
适当增加细微纸张纹理，但不要过度做旧。
不要生成虚假的技术标注和乱码。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 虚假技术标注
- 乱码
- 过度做旧
- 多图

## 最终检查要点

- 蓝白体系
- 主体轮廓清晰
- 50/50
- 单张

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

# 03-raster-distortion — Raster Distortion

- **风格名称（EN）：** Raster Distortion
- **中文说明：** 光栅线场实验海报
- **Prompt ID：** `03-raster-distortion`
- **上下区域比例：** 上 50% / 下 50%
- **适用场景：** 实验艺术、视觉错觉展、现代展览海报
- **推荐照片类型：** portrait, sculpture, architecture, product
- **核心视觉特征：** 平行光栅线、受控变形、线场推挤

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将用户单张照片制作成3:4竖版实验性艺术海报。
上半部分保留原始照片，保持主体结构、真实材质和自然光影。
下半部分由连续细密的平行光栅线条构建。
让原始照片主体仿佛成为隐藏的三维形态，从连续线场中向外推挤而出。
主体通过平滑的压缩、扩张、弯曲和负空间呈现。
不要使用独立描边或写实三维渲染。
线条应当连续、精确、有节奏，保持细密而克制。
只使用少量大型、受控的变形区域。
主体保持在下半部分约70%至80%的主要视觉范围内。
背景采用米白、浅灰或极浅暖色。
整体具有实验艺术、视觉错觉和现代艺术展览海报的气质。
禁止多图拼接和复杂装饰。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 独立描边
- 写实3D渲染
- 多图拼接
- 复杂装饰

## 最终检查要点

- 50/50
- 线连续
- 主体在 70-80% 视觉范围
- 无拼贴

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

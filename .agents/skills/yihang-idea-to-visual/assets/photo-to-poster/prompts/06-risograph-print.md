# 06-risograph-print — Risograph Print

- **风格名称（EN）：** Risograph Print
- **中文说明：** 复古孔版印刷
- **Prompt ID：** `06-risograph-print`
- **上下区域比例：** 上 45% / 下 55%
- **适用场景：** 复古出版物、丝网印刷艺术
- **推荐照片类型：** portrait, street, product, poster-subject
- **核心视觉特征：** 2-3油墨、网点、套印错位

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将单张照片制作成3:4竖版复古孔版印刷艺术海报。
上半部分为原始照片，保留真实画面。
下半部分将同一主体重新创作成复古丝网和Risograph印刷风格。
限制在2至3种油墨颜色。
使用：
- 深蓝色。
- 砖红色或橙色。
- 奶油白。
使用可见网点、细腻纸张颗粒和少量不均匀色版套印。
主体主要通过平面色块和剪影表达。
允许少量受控色彩错位，但不能因此模糊主体。
画面具有复古印刷出版物的艺术气质。
不要使用现代发光效果、照片拼接和复杂渐变。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 发光效果
- 照片拼接
- 复杂渐变
- 过多油墨色

## 最终检查要点

- 45/55
- 2-3色
- 主体清晰
- 无拼贴

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

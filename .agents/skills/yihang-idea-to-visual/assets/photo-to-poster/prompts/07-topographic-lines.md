# 07-topographic-lines — Topographic Lines

- **风格名称（EN）：** Topographic Lines
- **中文说明：** 地形等高线艺术
- **Prompt ID：** `07-topographic-lines`
- **上下区域比例：** 上 50% / 下 50%
- **适用场景：** 自然地貌研究、极简空间设计
- **推荐照片类型：** landscape, architecture, sculpture, portrait
- **核心视觉特征：** 等高线、曲率密度、自然色

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将单张照片制作成一张3:4竖版的地形等高线艺术海报。
上半部分保留原始照片。
下半部分根据照片主体的外形和空间轮廓，生成连续的地形等高线结构。
使用细密、连续、具有节奏感的弧线构成主体。
主体可以像地形隆起一样，由线条密度、曲率和间距变化表达。
从照片中提取2至3种自然颜色。
使用米白、浅沙色和深色线条构建空间层次。
主体必须可识别。
避免普通地图标记、文字标签和过多地图细节。
整体具有自然地貌研究、现代艺术和极简空间设计气质。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 地图标记
- 文字标签
- 过多地图细节
- 多图

## 最终检查要点

- 线连续
- 主体可识别
- 50/50
- 2-3色

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

# 11-ink-wash — Ink Wash

- **风格名称（EN）：** Ink Wash
- **中文说明：** 东方水墨艺术
- **Prompt ID：** `11-ink-wash`
- **上下区域比例：** 上 50% / 下 50%
- **适用场景：** 收藏级艺术印刷、现代东方展览
- **推荐照片类型：** landscape, architecture, plant, object
- **核心视觉特征：** 墨色浓淡、大留白、写意轮廓

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将用户单张照片制作成3:4竖版东方极简艺术海报。
上半部分保留原始照片。
下半部分把同一主体转化为现代水墨艺术表达。
通过墨色浓淡、留白、笔触和简洁轮廓重现主体。
主体结构必须能够识别。
使用黑、灰、米白及从原照片中提取的一种辅助色。
避免过度写实，避免复杂细节。
通过大面积留白表达空间和意境。
根据照片主体调整水墨表现：
山川可以呈现水墨地貌；
建筑可以呈现简练建筑轮廓；
植物可以呈现写意枝叶；
器物可以呈现简洁墨色剪影。
整体安静、现代、克制，具有收藏级艺术印刷质感。
不模仿任何具体在世艺术家的个人风格。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 模仿在世艺术家个人风格
- 过度写实
- 多图
- 乱码字

## 最终检查要点

- 主体可识别
- 大留白
- 50/50
- 单辅助色

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

# 02-linocut-travel — Linocut Travel

- **风格名称（EN）：** Linocut Travel
- **中文说明：** 油毡版画旅行手记
- **Prompt ID：** `02-linocut-travel`
- **上下区域比例：** 上 45% / 下 55%
- **适用场景：** 旅行手账、独立杂志、诗意双联
- **推荐照片类型：** travel, landscape, street, architecture
- **核心视觉特征：** 油毡/孔版质感、撕边纸、错位套印

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将单张原始照片制作成一张3:4竖版双联旅行艺术海报。
上半部分占45%，保留原始照片，尽可能不改变原始图像内容和主体结构。
下半部分占55%，将同一场景重新表现为极简油毡版画或孔版印刷插画。
画面印在奶油色纤维纸上，右侧具有自然撕边质感。
墨色具有颗粒感、不均匀印刷效果和轻微色版错位。
以平面剪影为主，辅以少量细线。
从原照片提取2至3种主色：
主体颜色作为点缀色；
深海军蓝用于结构和主体轮廓；
褪色浅彩色用于背景。
主体适当缩小，放置于右下方。
左上方保留大量留白。
底部使用简洁地平线色带。
左下角可以预留两行英文诗意文案的排版空间。
整体具有安静、诗意、旅行手账和独立杂志质感。
不要使用多张照片，不要制作照片拼贴。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 多照片
- 拼贴
- 高光塑料感
- 复杂渐变

## 最终检查要点

- 45/55 比例
- 撕边仅在艺术区
- 主体可识别
- 单张独立

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

# 08-paper-cut-relief — Paper Cut Relief

- **风格名称（EN）：** Paper Cut Relief
- **中文说明：** 纸雕浮雕艺术
- **Prompt ID：** `08-paper-cut-relief`
- **上下区域比例：** 上 45% / 下 55%
- **适用场景：** 纸艺展览、手工艺术印刷
- **推荐照片类型：** portrait, architecture, plant, object
- **核心视觉特征：** 层叠剪纸、纤维纹理、柔和光影

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将单张照片制作成3:4竖版艺术海报。
上半部分保留原始照片。
下半部分将照片主体转换为层叠纸雕艺术。
通过简洁的几何剪纸轮廓表现主体结构。
使用多层不同明度和颜色的纸张形成微妙层次。
纸张具有真实纤维纹理和细腻切割边缘。
颜色来源于原始照片，控制在3至4种颜色。
采用米白背景、大面积留白和克制构图。
主体不宜过大，保持视觉中心明确。
光影必须自然、柔和，不要形成夸张的3D塑料效果。
这是同一主体的单一纸雕艺术表达，不是多张照片拼贴。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 夸张3D塑料感
- 多照片拼贴
- 主体过大失控

## 最终检查要点

- 45/55
- 3-4色
- 柔和阴影
- 单主体

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

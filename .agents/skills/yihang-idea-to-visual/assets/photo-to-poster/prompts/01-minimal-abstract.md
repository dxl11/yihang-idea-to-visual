# 01-minimal-abstract — Minimal Abstract

- **风格名称（EN）：** Minimal Abstract
- **中文说明：** 极简几何抽象海报
- **Prompt ID：** `01-minimal-abstract`
- **上下区域比例：** 上 50% / 下 50%
- **适用场景：** 国际设计工作室、现代建筑海报、高级艺术展览
- **推荐照片类型：** architecture, product, portrait, still-life
- **核心视觉特征：** 几何色块、大留白、2-4色克制配色

## 色彩规则

从原照片提取主色；遵守本风格 Prompt 内的色数与色相限制。上半区仅允许轻微摄影调色。

## 详细生成 Prompt

```text
将用户提供的单张照片制作成一张高级极简艺术海报。
画布采用3:4竖版，上下两个区域高度严格为50%和50%。
每张照片独立处理，不允许多图拼接。
上半部分保留原始照片，尽可能使用原始像素作为图层。保持主体结构、真实质感、自然光影和原有色彩氛围，仅进行轻微高级摄影调色。允许自然扩展天空、地面和环境背景，但不得拉伸、变形或改变主体。
下半部分提取照片中主体最具识别性的轮廓与结构，使用简洁几何形状、扁平色块、细线条和大面积留白进行极简抽象表达。
不要写实插画，不要复杂细节。必须保留主体关键特征，让人能够识别原照片中的主体。
配色从原照片中提取，使用克制的2至4种颜色。
下半部分采用米白或浅色背景，主体居中或略偏中心。
可以为后期排版预留简洁英文标题和编号区域。
整体具有国际设计工作室、现代建筑海报和高级艺术展览视觉感。
禁止相框、白边、贴纸、多照片拼贴和装饰性阴影。
```

必须与 [base-prompt.md](base-prompt.md) 一并执行。

## 禁止出现的视觉元素

- 相框
- 白边
- 贴纸
- 多照片拼贴
- 装饰性阴影
- 复杂写实插画

## 最终检查要点

- 上下严格 50/50
- 主体可识别
- 2-4 色
- 无拉伸

## 生产提醒

- 一张输入照片 → 一张独立海报。
- 上半区用原图像素图层合成；下半区才是生成重点。
- 画布默认 1080×1440（3:4）。

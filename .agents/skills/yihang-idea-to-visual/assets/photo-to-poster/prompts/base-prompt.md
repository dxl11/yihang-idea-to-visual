# Base Prompt — Photo-to-Poster

统一基础指令。与任一风格 Recipe 组合使用。每次只处理**当前这一张**照片。

```text
你将收到一张用户上传的原始照片。
请以这张照片作为唯一的主体、场景和视觉参考来源。
将其创作成一张3:4竖版艺术海报。
每次只处理当前这一张照片，不得调用、混合或拼接其他照片。

整体由上下两个视觉区域组成。

上半部分：
保留输入照片中的主要主体、结构、姿态、空间关系和真实场景。
不得改变人物数量、物体数量、主要建筑结构和主体身份。
不得拉伸、扭曲或重新设计原始主体。
按照所选风格的指定比例安排照片区域。
优先使用原始照片作为实际图层。
可以根据风格进行轻微摄影调色，但不得凭空创造主体细节。
如果需要扩展背景，只能扩展环境，不得改变主体。

下半部分：
根据原始照片中的主体和场景，生成指定风格的原创艺术化视觉表达。
必须保留原主体最具识别性的轮廓和关键结构。
可以将主体抽象化、几何化、平面化或转化成版画、线描等视觉语言。
不得生成与原照片无关的主体。
颜色优先从原始照片提取。
使用克制的色彩系统和适当的留白。

最终作品：
单张、独立、完整的艺术海报。
无多照片拼接。
无照片拼贴。
无九宫格。
无相框和多余白边。
不要生成随机乱码文字。
整体构图必须适合3:4竖版发布。
```

## Production rules (always)

1. 一张输入照片对应一张独立海报。
2. 多张照片逐张处理，不得合并到同一生成请求。
3. 画布统一 3:4，默认 1080×1440。
4. 上半部分由 Pillow 使用原始照片实际像素合成，不依赖模型重绘原图冒充保留。
5. 下半部分才是图像生成重点。
6. 英文文案如需出现，优先后处理精确排版，禁止模型乱码字。

## Color

| Role | Token | Hex | Use |
|---|---|---|---|
| Ground | `safelight-amber` | `#ffb000` | Banner wash, emphasis |
| Depth | `darkroom-black` | `#1a0f08` | Banner field |
| Print | `silver-print` | `#c9c2b8` | Emerging type / secondary |
| Paper | `tray-white` | `#f7f3ea` | Timer card / paper edges |
| Ink | `grease-pencil` | near-black on paper | Commands, stations |

Strategy: **Committed** — amber owns the banner atmosphere; Markdown body stays GitHub-readable.

## Type

- Banner: photographic / grease-pencil display (raster)
- README body: GitHub Markdown defaults (platform constrained)
- Commands: fenced monospace as timer-card receipts

## Materials & Motifs

- Enamel developer trays
- Wet silver print emergence
- Grease-pencil station marks: EXPOSE · DEVELOP · FIX · WASH · DRY
- Timer cards for install commands
- Hairline “tray edge” rules (`---`)

## Composition

1. Full-bleed banner proves the world  
2. Timer-card install is the loudest object below the fold of the banner  
3. Station table maps darkroom ritual → skill workflow  
4. Numbered docs sections preserve install accuracy and test markers  

## Motion

None in Markdown. Banner is a still that implies chemical emergence.

## Do / Don't

**Do:** keep install commands exact; map stages to stations; protect single-skill honesty.  
**Don't:** purple SaaS gradients; badge-only heroes; invent customers/metrics; bury install below long prose.
